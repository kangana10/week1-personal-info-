# Personal Information Manager

## Project Description
This is my first Python internship project.  
The program stores and displays personal information using Python concepts such as variables, user input, loops, validation, string methods, and formatted output.

The project was created to practice beginner-level Python programming and understand how user interaction works in a Python program.

---

# Features

- Stores static personal information
- Takes user input from the user
- Validates empty input fields
- Uses string formatting methods
- Displays information in a clean and formatted structure
- Calculates age in months
- Includes welcome and goodbye messages

# Challenges & Solutions

## Challenge 1
User might enter empty input.

### Solution
Added validation using `while` loops to make sure the user enters proper values.

---

## Challenge 2
Formatting the output neatly.

### Solution
Used f-strings, separators, and spacing for better readability.

---

## Challenge 3
Handling extra spaces and inconsistent text formatting.

### Solution
Used string methods like:
- `.strip()`
- `.title()`
- `.capitalize()`

to clean and format user input properly.
